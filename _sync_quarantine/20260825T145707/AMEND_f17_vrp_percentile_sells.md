# AMENDMENT 1 — F-17, OWN-HISTORY VRP-PERCENTILE SELLS
## Dated 2026-08-25, Frontier Scout lane. `DECL_f17_vrp_percentile_sells.md` is NOT edited.
## Must land before F-17's first fill. Zero records today. **Zero trials.**

**The inherited defect.** F-17's rule adopts F-4's event-free window *by prose reference*
("event-free per F-4's window rule"). That rule is unevaluable — the I-4 spine holds no forward
dates (`2ef8e5d`) — so **F-17's eligible set is empty for the same reason F-4's is**, and it
would report skips rather than entries indefinitely (`AMEND_f4` §2).

**A second hazard this amendment closes, and it is the reason F-17 gets its own file rather than
riding F-4's:** a rule adopted *by reference* to another book's prose **changes silently when
that book is amended**. F-4 has three live routes (forward feed / labelled cadence proxy /
withdrawal) and they are not equivalent — under the proxy route F-17 would inherit a
*measured-miss-rate* screen while its own declaration still claimed a clean one. **Each book's
chain anchors on its own declaration, so each must adopt the repaired rule explicitly.**

**The amendment.** F-17 adopts **whichever route F-4's amendment resolves to, by explicit
reference to `AMEND_f4_eventfree_premium.md` and its committed content hash — not by prose** —
and F-17 may not arm before that resolution. If F-4 resolves to route (B), **F-17's hypothesis
is likewise re-declared as "event-free at a measured miss rate of X%"** and X travels with every
verdict sentence. If F-4 withdraws, F-17 withdraws with it: its cleanliness screen is F-4's, and
a VRP-percentile sell book without an event screen is a different hypothesis needing its own
declaration.

**Cross-book dedup unaffected:** the frozen F-4 > F-17 > F-10 priority stands whatever the route.
