**D4 — THE OBJECT IS A CHANGE IN RELATIVE STANDING, AND §1'S MECHANISM PROSE OVERSTATES IT.**
`composite_from_frame` standardises **within each date** (`zscore(sub[c])` on a per-date slice)
before the renormalised weighted sum, so `c(i,t)` is a *relative* position in that date's
cross-section, not an absolute level. Therefore:

> A name whose fundamentals improve exactly as much as the cross-section's improve has
> **Δc ≈ 0**. A name standing still while others deteriorate has **Δc > 0**.

§1 describes the mechanism as *"a name whose whole fundamental picture is improving"* — that is an
**absolute** improvement, and the object measures a **relative** one. **This does not make the
register unexecutable and is not a reason to reject it**: a cross-sectional book ranks names
against each other, so relative standing is the decision-relevant quantity, and it is arguably
the better object. But the two are different, and **any verdict here is a verdict about relative
standing** — that sentence travels with the result in either direction.

## 1. Mechanism, with its literature and the literature's status

Underreaction to fundamental *improvement*: Novy-Marx (NBER w20984) argues price momentum is

standing rule that this project has killed published results before. The local translation:
a name whose *whole fundamental picture* (7-theme composite) is improving may outperform a
name with the same level and a flat or decaying picture, if the market prices levels faster
than trajectories.
